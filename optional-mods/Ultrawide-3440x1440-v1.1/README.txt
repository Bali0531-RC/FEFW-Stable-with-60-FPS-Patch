ULTRAWIDE 3440x1440 PATCH for Fire Emblem: Fortune's Weave (optional, OFF unless you install it)

By Kompas9, version 1.1, from https://github.com/Kompas9/Switch-Game-Patches (MIT licence,
see LICENSE-Kompas9.txt; full notes in ULTRAWIDE-Kompas9.md). Included unchanged.

For 21:9 monitors at 3440x1440 only. It widens the 3D camera to 43:18 and keeps the HUD,
menus and pre-rendered movies centred at 16:9 (movies get black side bars).
Only for the game version whose build ID starts DB93B0125F485060 (version 1.1.0).

TO TURN IT ON
1. Close the game.
2. Copy this whole Ultrawide-3440x1440-v1.1 folder into
   user\load\04007EF01F8AE000\   (next to the 60fps folder)
   (or right-click the game > Open Mod Data Location and copy it there).
3. In Emulation > Configure > Graphics, set Aspect Ratio to "Stretch to Window", and play
   fullscreen (or in a 3440x1440 window).
4. Start the game. Properties > Add-Ons should list Ultrawide-3440x1440-v1.1 ticked.

TO TURN IT OFF
Untick it in Properties > Add-Ons (or delete the folder from user\load\04007EF01F8AE000\)
and set Aspect Ratio back to "Default (16:9)".

Limited testing by its author (in another emulator); report problems with a screenshot.
It works alongside the 60fps option.
